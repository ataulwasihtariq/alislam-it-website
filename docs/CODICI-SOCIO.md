# Codice socio (predisposizione, disattivata)
- Il codice socio è il nome utente; ruoli: `amj_membro`, `amj_amila`, `amj_sadr`.
- Shortcode: `[amj_riservato ruolo="amj_amila"]…[/amj_riservato]` e `[amj_accesso]`.
- Attivazione: opzione `amj_codici_attivi = 1`. Finché è 0 mostrano «in preparazione».
- Pagine riservate: noindex. Nessun dato sensibile nel sito pubblico.
- Da decidere con l’amministratore: password iniziale, recupero accesso, conservazione dati (GDPR).
