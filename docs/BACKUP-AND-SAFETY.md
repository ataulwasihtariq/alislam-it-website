# Backup and safety rules

- No material change to the live site without a verified full backup (files + database) that has been test-restored.
- Publishing or replacing key pages, menu, homepage, plugins, URLs, forms or privacy text needs explicit approval.
- Allowed without approval: read-only audit and unpublished drafts.
- Status (Nov 2026): no full backup exists; find out who hosts the site and can run one.
- Every change gets a rollback note: what changes, where, how to undo.
